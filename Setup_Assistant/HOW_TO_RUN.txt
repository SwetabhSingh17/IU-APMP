┌────────────────────────────────────────────────────────────────────────┐
│                          WHAT WILL HAPPEN?                             │
└────────────────────────────────────────────────────────────────────────┘

When you run the installation script, the computer will:

1. Download and install the "brain" of the application (Node.js)
2. Download and install the "memory" of the application (PostgreSQL database)
3. Set up all the pieces needed to run the website
4. Start the website automatically!

This will take about 5-10 minutes. Don't worry if you see lots of text 
scrolling by - that's normal! The computer is just telling you what it's doing.


════════════════════════════════════════════════════════════════════════
                    FOR WINDOWS USERS (Windows 10/11)
════════════════════════════════════════════════════════════════════════

🎯 EASIEST METHOD - Use the Batch File:

STEP 1: Find the Setup_Assistant folder
   • Open File Explorer (the folder icon on your taskbar)
   • Navigate to where you saved the IU-APMP folder
   • Open the "Setup_Assistant" folder inside it

STEP 2: Run the installation
   • Look for: INSTALL_WINDOWS.bat
   • DOUBLE-CLICK on "INSTALL_WINDOWS.bat"
   • Click "YES" when Windows asks for permission
   
   💡 This file automatically handles all security settings!

STEP 3: Wait patiently (see STEP 5 below for what to expect)

───────────────────────────────────────────────────────────────────────

⚙️ ALTERNATIVE METHOD - If you see a "Script Execution" error:

If you get an error like "running scripts is disabled", follow these steps:

STEP 1: Open PowerShell as Administrator
   • Press Windows key
   • Type "PowerShell"
   • RIGHT-CLICK on "Windows PowerShell"
   • Select "Run as administrator"
   • Click "YES" when asked for permission

STEP 2: Navigate to the Setup_Assistant folder
   • In PowerShell, type: cd 
   • DON'T PRESS ENTER YET!
   • Open File Explorer, find the Setup_Assistant folder
   • Drag the Setup_Assistant folder into the PowerShell window
   • Now press Enter

STEP 3: Run the installation with security bypass
   • Type this EXACTLY:
     PowerShell -ExecutionPolicy Bypass -File install_windows.ps1
   • Press Enter

STEP 4: When a blue box appears
   • A blue window will pop up asking "Do you want to allow this?"
   • This is normal and safe!
   • Click "YES" or "Run anyway"
   
   💡 The script needs permission to install software on your computer.

STEP 5: Wait patiently
   • You'll see lots of text scrolling in the blue window
   • This is the computer downloading and installing everything
   • DO NOT CLOSE THE WINDOW!
   • This will take 5-10 minutes
   
   What you'll see:
   ✓ "Installing Node.js..." (the brain)
   ✓ "Installing PostgreSQL..." (the memory)  
   ✓ "Installing dependencies..." (the tools)
   ✓ "Setting up database..." (the storage)

STEP 6: Success!
   • When you see "🎉 Installation Complete!"
   • Your web browser will open automatically
   • The website will be at: http://localhost:3000
   
STEP 7: Stop the server (when you're done)
   • Go back to the blue PowerShell window
   • Press Ctrl+C on your keyboard
   • The website will stop running

════════════════════════════════════════════════════════════════════════
                           TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

PROBLEM: "winget is not recognized" (Windows)
SOLUTION: You need to install winget first:
   1. Open Microsoft Store
   2. Search for "App Installer"
   3. Install it
   4. Restart your computer
   5. Try the installation again

PROBLEM: "command not found" (Mac/Linux)
SOLUTION: Make sure you're in the right folder:
   1. Open Finder/File Manager
   2. Find the Setup_Assistant folder
   3. Drag it into Terminal (after typing "cd ")
   4. Try again

PROBLEM: "Permission denied"
SOLUTION: You need to make the file executable:
   • Mac/Linux: Run "chmod +x install_mac_linux.sh" first

PROBLEM: Antivirus blocks the file or shows a blue warning
SOLUTION: 
   1. If Windows SmartScreen (blue box) appears, click "More info" 
      then click "Run anyway".
   2. If a third-party Antivirus (Norton, McAfee) completely blocks it, 
      you can either temporarily pause it, OR scroll down and use the 
      "Manual Installation" method below.

PROBLEM: Installation stops or freezes
SOLUTION: 
   1. Close the Terminal/PowerShell window
   2. Start over from STEP 1
   3. If it happens again, restart your computer first

PROBLEM: "Port 3000 already in use"
SOLUTION: Another program is using that port:
   1. Restart your computer
   2. Try the installation again

PROBLEM: "db:push" fails or Database Connection Error
SOLUTION: The website cannot talk to the database. This usually means:
   1. The PostgreSQL password in your .env file doesn't match your actual password.
      Fix: Open the .env file in Notepad and change DB_PASSWORD to match.
   2. The PostgreSQL service isn't running.
      Fix: Search Windows for "Services", find "postgresql", and click Start.
   3. Once fixed, manually run "npm run db:setup" in the IU-APMP folder.

PROBLEM: Can't find the file
SOLUTION: Make sure you:
   1. Unzipped the project folder completely
   2. Look inside IU-APMP folder
   3. Then inside Setup_Assistant folder

                      NEED MORE HELP?
════════════════════════════════════════════════════════════════════════

If the automatic installation doesn't work (or gets blocked by Antivirus), you can install manually:

1. Install Node.js:
   • Visit: https://nodejs.org/
   • Download the "LTS" version (recommended for most users)
   • Run the installer

2. Install PostgreSQL:
   • Visit: https://www.postgresql.org/download/
   • Choose your operating system
   • Download and run the installer
   • IMPORTANT: Set the password to "root123" when asked!

3. Run the commands manually:
   • Open your Terminal or Command Prompt in the IU-APMP folder
   • Type: npm install
   • Copy .env.example to .env
   • Type: npm run db:setup
   • Type: npm run dev

════════════════════════════════════════════════════════════════════════
                       UPDATING AN EXISTING APPLICATION
════════════════════════════════════════════════════════════════════════

If you already have the application running and need to update it without losing data:

1. Stop your running server (Ctrl+C).
2. Get the new code:
   - If using Git: Type `git pull origin main`
   - If using ZIP: Extract the new ZIP over the old folder, OR to a new folder and copy your old `.env` file into it.
3. Open Terminal/PowerShell in the folder.
4. Type: `npm install` (to install any new tools)
5. Type: `npm run db:ensure` (to safely verify and update the database schema without losing data)
6. Type: `npm run dev` to start the server again!
   (Note for Windows users: You can also simply double-click start_server.bat!)
